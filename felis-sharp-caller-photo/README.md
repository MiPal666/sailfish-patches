# Sharp Caller Photo

Patchmanager patch for Sailfish OS Phone.

## Features

- sharp caller photo without blur
- black call-screen background
- caller photo displayed with its original aspect ratio
- cleaner incoming and active call layout
- removes the large green swipe overlay while keeping the answer/reject gesture functional

## Compatibility

Tested on:

- Jolla Phone 2026
- Sailfish OS 5.2.0.17
- Patchmanager 3

## Files

- `unified_diff.patch` — system QML changes
- `patch.json` — Patchmanager metadata
